**É possível criar um site com o Claude Code sem saber programar?** Pode começar por uma página simples, descrevendo o que pretende em português e revendo o resultado. O Claude Code é uma ferramenta de inteligência artificial que cria e altera ficheiros de código e executa tarefas de desenvolvimento. Para um cabeleireiro, eletricista, montador de móveis ou consultor, um primeiro projeto útil é uma página com serviços, zona de atendimento e contacto. Neste tutorial, vai aprender a preparar esse projeto, escrever o pedido e verificar se a página funciona.

## 1. Prepare o Claude Code no computador

Instale a aplicação oficial do Claude, entre na sua conta e abra o separador **Code**. Esta opção permite trabalhar através de uma interface gráfica, sem utilizar o terminal, e requer uma subscrição elegível, como o Claude Pro. Crie uma pasta vazia chamada “site-do-meu-negocio”; no separador Code, escolha o ambiente local e selecione essa pasta. Consulte o [guia oficial de instalação](https://code.claude.com/docs/en/desktop-quickstart) se as opções apresentadas forem diferentes.

## 2. Defina o objetivo da página

Antes de pedir um design, decida o que pretende que o visitante faça: telefonar, pedir um orçamento ou solicitar uma marcação. Reúna o nome do negócio, serviços, localidades onde trabalha, horário, contactos e fotografias próprias. Um eletricista pode destacar instalações e reparações na sua zona; um cabeleireiro pode apresentar serviços e encaminhar pedidos de marcação para o WhatsApp. Começar com um objetivo claro facilita a construção e a avaliação do resultado.

## 3. Escreva um pedido específico

Pode copiar e adaptar este exemplo:

> Cria um site de uma página para o meu negócio de [atividade], em [localidade], em português de Portugal. Inclui apresentação, serviços, zona de atendimento, horário e um botão para pedir orçamento pelo WhatsApp. Usa os dados que vou fornecer e pergunta pelo que faltar. Não inventes preços, avaliações ou certificações. Quero uma página simples, legível no telemóvel, em HTML e CSS, sem formulário nem base de dados nesta primeira versão. Antes de criar os ficheiros, apresenta o plano e espera pela minha aprovação.

Este pedido, também chamado *prompt*, dá à ferramenta um objetivo e limites concretos.

## 4. Veja o resultado e peça alterações pequenas

Depois de aprovar o plano, peça ao Claude Code para criar a página e explicar como a abrir no navegador. Analise-a como se fosse um cliente: percebe-se imediatamente o serviço? A zona de atendimento está visível? O contacto é fácil de encontrar? Peça uma alteração de cada vez, por exemplo: “Aumenta o texto no telemóvel” ou “Coloca o botão de orçamento junto aos serviços”. Confirme pessoalmente os contactos e teste os botões; uma mensagem da IA a dizer que terminou não substitui essa verificação.

## 5. Prepare a publicação e a descoberta no Google

Peça um título descritivo, como “Eletricista em Almada | Nome do Negócio”, uma descrição da página e respostas claras às dúvidas reais dos clientes. Use apenas localidades onde trabalha e informação que consegue confirmar. Depois, peça instruções para publicar a página num alojamento compatível com HTML e CSS e ligar o seu domínio, verificando os custos antes de contratar. Uma página aberta no computador ainda não está publicada na Internet. Após a publicação, volte a testar o endereço, os contactos e a apresentação no telemóvel.

## 6. Evolua para um pequeno sistema

Quando dominar a página, experimente um protótipo para organizar pedidos de orçamento ou acompanhar trabalhos, começando com dados fictícios. Um sistema que guarda contactos, gere marcações ou aceita pagamentos exige decisões adicionais sobre acessos, armazenamento, cópias de segurança e testes.
